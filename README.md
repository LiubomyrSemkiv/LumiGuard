# LumiGuard - Smart Autonomous UPS 🔋
LumiGuard is an intelligent backup power system designed for long-term autonomous operation with real-time IoT monitoring[cite: 82]. 

## Features
* **Hardware:** ESP32 microcontroller, TP4056 charging module, DC-DC step-up converter, and relays[cite: 84, 85].
* **Telemetry:** Real-time monitoring of voltage, battery charge, and temperature[cite: 88].
* **Backend:** Node.js server receiving data via HTTP POST requests at `/api/telemetry`[cite: 86].

*Note: This repository contains the ESP32 firmware simulating the telemetry data and the project presentation.*
